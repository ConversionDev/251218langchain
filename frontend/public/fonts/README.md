# 폰트 (stroke-dashoffset 쓰기 연출용)

**Nanum Brush Script** TTF 파일이 필요합니다.

1. [Google Fonts - Nanum Brush Script](https://fonts.google.com/specimen/Nanum+Brush+Script) 접속
2. "Download family"로 TTF 다운로드
3. 압축 해제 후 `NanumBrushScript-Regular.ttf` 를 이 폴더(`public/fonts/`)에 넣어 주세요.

파일이 없으면 인트로는 기존 방식(clipPath 텍스트 reveal)으로 동작합니다.
