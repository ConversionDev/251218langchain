# 환경 데이터 매핑 테이블 통합·보강 전략

목표: **환경 데이터 매핑 테이블.xlsx** + **mapping_YYYYMMDD.xlsx**를 CAS 기준으로 합치고, ESG·다국어·배터리·동의어로 보강해 한 번에 다국어 보고·공급망·검색에 쓸 수 있게 한다.

## 1. 두 Excel 통합
- **입력**: ① 환경 데이터 매핑 테이블.xlsx (원본) ② mapping (CAS당 1행, 12개 언어)
- **기준**: CAS로 매칭
- **산출**: 통합 Excel 1개 (원본 열 + 12개 언어 열)

## 2. 정보 범위
- **ESG 우선 언어**: 필수 4(영·한·중·일) + EU 4(독·프·스·포) + 추가 4(베트남·태국·인도네시아·아랍) = 12개
- **배터리 물질**: 리튬·코발트·망간·니켈·형석·흑연·알루미늄, 양극재/전해질/바인더/공정 등 반드시 포함
- **행 형식**: 1행 = 1별칭(내부 표기명), **완전 동의어**만

## 3. 동의어 보강
- **PubChem**: 전체 CAS 동의어(영문) 병합
- **KECI**: 한국 공식 물질명(영문/국문)
- **ECHA**: EU 공식·다국어 (ECHA_API_URL 설정 시)

## 4. 실행 순서
1. (선택) 원본에서 유니크 CAS 추출 → `export_original_cas_for_mapping.py` → CSV
2. `run_mapping` (필요 시 --input 위 CSV) → mapping Excel
3. `vocabulary_builder --original 원본.xlsx --mapping mapping.xlsx --output 결과.xlsx` → 한 번에 통합·보강·중복 제거

## 5. 최종 산출물
- 한 파일에 원본 구조 + 12개 언어 확장 + PubChem/KECI/ECHA 보강
- (CAS, 내부 표기명) 중복 제거
