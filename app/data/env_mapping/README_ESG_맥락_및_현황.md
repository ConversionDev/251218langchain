## 1. 맥락 (목표·도메인·문서 역할)

**한 줄**: **자동차 배터리(EV 배터리)** 공장의 **전력** 데이터로 **시계열 분석·이상치 탐지·예측**을 한다.

**원칙**: 기준·참고 자료·데이터셋은 **가급적 최근 기준**으로 둔다. 같은 종류면 2024~2025 우선, 없을 때만 이전 연도 참고.

---

### 1.1 목표 (해야 하는 것)

| 목표 | 내용 |
|------|------|
| **시계열** | 공정·라인별 전력(usage) 시계열 분석 — 추세, 주기, 시각화. |
| **이상치 탐지** | Rule 1~6 기반 검증(음수, 설비 정격, 계약 전력, 생산량 대비, 설비 가동 대비, 시간대 대비) + validation 로그. |
| **예측** | 전력 수요 예측. 추후 예측 결과 테이블 추가 시 “예측 대비 이탈” 이상치까지 확장 가능. |

→ 입력은 **measurements**(검증 통과한 전력 시계열), 기준은 **설비 정격·계약 전력·공정별 기대 전력·shift별 범위** 등.

---

### 1.2 도메인 (집중하는 것)

| 구분 | 내용 |
|------|------|
| **산업** | **자동차 배터리 (EV 배터리)** — 전기차용 리튬이온 배터리 셀·모듈·팩 제조 공정. |
| **데이터** | 해당 공장의 **전력(usage)** + 생산량(production), 설비 가동 수(equipment_ct), 시간대(shift). **손실량(scrap)·산출 폐기물(waste)** 도 데이터셋 생성 시 함께 만듦(학습·효율 지표용). |
| **기준·참고** | 설비 정격, 공정별 단위 생산당 전력(kWh/kWh), 계약 전력, 손실·폐기물 등 **배터리 공정 맥락**에서 의미 있는 수치·문서를 우선함. |

→ 일반 제조·건설·금속 채굴 등이 아니라 **배터리(자동차용)** 에 집중. 참고 데이터셋·문서도 **배터리 관련 최근 자료**를 우선하고, 없을 때만 일반 제조 참고.

---

### 1.3 이 맥락에서 문서·데이터 역할

| 문서·데이터 | 역할 |
|-------------|------|
| **README_ESG_Rule_및_설비기준.md** §1 | 시계열·이상치 탐지용 Rule 1~6 기준·상태 정리. |
| **README_ESG_Rule_및_설비기준.md** §2 | Rule 2·4용 **배터리 공장** 기준 — MDPI 2025(헝가리 배터리 공장), 설비 정격(코터·건조기 등). |
| **본 문서 §4** | 한국 기준 + **배터리/자동차 배터리** 관련해 참고할 데이터셋·통계. |
| **README_배터리_손실량_폐기물_통상참고치.md** | 손실량·산출 폐기물 **임의 생성용 통상 참고치**(공정별 scrap/waste 비율). 취업 준비·포트폴리오용 더미 생성 시 사용. |
| **전기요금표, 전력수요 CSV, 수요관리** | 한국 전력 수요·요금·계약 — Rule 3·6·예측 보조. |
| **KCI 논문** | 전극 공정 등 **배터리 공정** 구조 참고. |
| **measurements / validation** | 자동차 배터리 공장 전력 시계열(검증 통과분) + 이상 시 에러 로그. 더미/학습용 생성 시 **손실량·산출 폐기물** 컬럼 포함해 같이 생성. |

---

### 1.4 정리

- **할 일**: 시계열 + 이상치 탐지 + 예측.  
- **범위**: **자동차 배터리** 공장 전력.  
- **기준·참고**: **가급적 최근 기준**(2024~2025 우선). 그다음 배터리 관련·한국 데이터 우선.  

이 맥락을 기준으로 `env_mapping` 폴더의 README·데이터를 읽고 쓰면 됨.

## 2. 지금 상황 & 구현

**한 줄**: 필요한 데이터·기준은 다 갖춰져 있음. 더 찾을 데이터 없고, md·`env_mapping`을 참고해 더미·검증 파이프라인이 돌아가면 됨.

**구현 위치(더미 생성)**: `app/training/pipelines/esg_dummy/run_generate_measurements.py` — `profile.json` 생성 후 `measurements.csv` / `validation_logs.csv` 출력. 선택: `app/data/esg_dummy/profile_source.json`(수동 덮어쓰기), `--output-labeled` 시 `labeled_slots.csv`.

---

### 2.1 하고 있는 것

- **자동차 배터리(EV)** 공장 **전력** 데이터로 시계열·이상치 탐지·예측.
- **6가지 Rule**(음수, 설비 정격, 계약 전력, 생산량 대비, 설비 가동 대비, shift 대비)로 검증.
- **measurements**: **정상 행** + **Rule 3(CONTRACT_EXCEED)** 시간대(해당 시각 전 라인 usage 부풀림) 행만 포함. **그 외 단일 Rule·다변량 이상 행은 measurements에 넣지 않고** `validation_logs`(및 라벨 파일)에만 기록.
- **validation**: 에러 로그(`error_type`, `value`, `threshold`, `row_number`). **손실량(scrap)·산출 폐기물(waste)** 는 정상·CONTRACT 행 및 프로파일 구간 샘플로 생성.
- **시간 컬럼**: 최신 생성기 기준 **`measurements.csv`에 `hour`(1~24) 포함** — 시계열·이동평균은 이 컬럼 기준. 예전 파일은 `hour` 없을 수 있음 → 재생성. **`labeled_slots.csv`** 는 계속 `noticedate`+`hour`+라벨. 상세는 `README_ESG_Rule_및_설비기준.md` 상단 「구현·스키마 갱신」.

---

### 2.2 가지고 있는 것 (추가로 찾을 필요 없음)

| 구분 | 내용 |
|------|------|
| **Rule 기준** | Rule 1~6 기준·출처·상태 → `README_ESG_Rule_및_설비기준.md` §1 |
| **설비 정격·공정별 전력** | MDPI 2025, MTI·켐시스템 등 → `README_ESG_Rule_및_설비기준.md` §2 |
| **계약 전력** | 2025 전기요금표 PDF (env_mapping 보유) |
| **손실량·산출 폐기물** | 통상 참고치(공정별 scrap/waste 비율) → `README_배터리_손실량_폐기물_통상참고치.md` §3.2; 빌드 시 **자동 파싱**되어 `profile.json`의 라인별 `scrap`/`waste` 구간으로 반영 |
| **더미 생성 전략** | 정상 프로파일, scrap/waste 범위, Rule별 이상 시나리오 → `docs/esg-dummy-data-strategy.md` |
| **맥락·문서 역할** | 목표, 도메인, 문서 역할 → 본 문서 §1 |
| **데이터 파일** | 전력수요 CSV, 수요관리 CSV, 전기요금표 PDF, MDPI 보조 엑셀(에너지·물·가스) 등 env_mapping에 보유 |

→ **더 찾아야 할 데이터 없음.**

---

### 2.3 손실량·산출 폐기물

- **현재 가진 것으로 다 나타낼 수 있음**: 통상 참고치 문서 + 더미 전략으로 scrap/waste 범위 정해 두고 생성하면 됨.
- **외국**: 손실량·산출 폐기물을 **다운로드할 수 있는 공개 데이터**는 없음. **문헌·사이트**에서 참고한 수치를 바탕으로 통상 참고치(md)를 만든 상태. (Kuki et al. MDPI 2025, Kallitsis, GREET 등)

---

### 2.4 앞으로 할 일

- `cd app` 후 `python -m training.pipelines.esg_dummy.run_generate_measurements` 로 데이터 갱신; 검증은 `verify_esg_dummy_data.py` 등 파이프라인 스크립트 참고.
- **다변량(복합) 이상**은 `MULTIVARIATE_*` **5종**만 존재하며 measurements 비포함·validation 전용 — 계산 기준은 `training/pipelines/esg_dummy/README.md` §다변량.
- **새 md**는 필요할 때만 추가.

## 3. 전력 파이프라인 사용 현황 (`run_generate_measurements` 기준)

`run_generate_measurements.py`(전력·이상치·예측용 더미 생성) 기준으로 **app/data/env_mapping** 내 자료 사용 여부 정리.  
**전력 파이프라인에서 전부 사용**하도록 반영됨.

---

### 3.1 사용 중 (전력 파이프라인에서 읽음·훑음)

| 구분 | 파일/패턴 | 용도 |
|------|-----------|------|
| **전력 수요 CSV** | `*.csv` (루트) | `load_power_demand_patterns()` — (날짜, 시간)별 수요 비율. 2021~2025 전부 사용 |
| **요금표·전력 PDF** | `전기요금`, `전기요금표` 포함 | 시행일 최신순 훑어 계약 전력 파싱. 최신 1건 = Rule 3 기준 |
| | `전력` + `요금표` (예: 전력_요금표) | 동일하게 요금표로 인식해 훑음 |
| | `kepco` + `electric`/`charges`/`요금` (예: kepco_electric_charges_list_total.pdf) | 동일 |
| | `YYYYMMDD(high).pdf`, `YYYYMMDD(low).pdf`, `YYYYMMDD(total).pdf` | 시행일로 인식해 요금표 목록에 포함·훑음 |
| | `YY.MM.DD+...` (예: 23.05.16+전력_요금표) | 시행일 파싱 후 훑음 |
| **참고 PDF** | 그 외 루트 PDF (예: KCI_FI003087224.pdf) | `_list_reference_pdfs()` → 참고 문서로 훑고, 텍스트 길이 등 기록 |
| | `mdpI/*.pdf` (예: Supplementary_Information.pdf) | 동일하게 참고 문서로 훑음 |
| **프로파일** | `profile_source.json` | 계약·정격 등 수치 오버라이드(선택) |
| **Rule 4·설비** | `README_ESG_Rule_및_설비기준.md` | Rule 4용 단위 생산당 전력 파싱 |
| **손실·폐기물** | `README_배터리_손실량_폐기물_통상참고치.md` | 공정별 scrap/waste 정상 범위(%) |
| **MDPI** | `mdpI/*.xlsx` | Rule 4 보강(kWh/kWh 등) |
| **README** | 루트의 `README*.md` 전부 | `tariff_contract_history.json`의 `readmes_scanned`에 이름·크기 기록 (전부 훑음) |

---

### 3.2 요약

- **CSV**: 루트의 모든 CSV 사용 (전력 수요·수요관리).
- **PDF**: 요금표 성격(전기요금표, 전력_요금표, kepco, YYYYMMDD 등)은 시행일 최신순으로 전부 훑고 계약 전력 파싱. KCI, mdpI/Supplementary 등 나머지 PDF는 참고 문서로 한 번씩 훑어 이력에 기록.
- **README**: `README_ESG_Rule_및_설비기준.md`(Rule4)·`README_배터리_손실량_폐기물_통상참고치.md`(§3.2)는 내용 파싱; 나머지 `README*.md`는 훑은 목록으로 `readmes_scanned`에 기록.
- **스크립트** (check_battery_final.py 등): 데이터가 아니라 실행용 스크립트라 파이프라인 입력에서는 제외.

결과는 `app/data/esg_dummy/tariff_contract_history.json`에서 확인 가능.

## 4. 참고 데이터셋 (한국 기준)

**맥락**: **자동차 배터리(EV 배터리)** 공장 전력의 **시계열·이상치 탐지·예측**용.

- **가급적 최근 기준**: 참고·데이터셋은 **최신 연도 우선**(2024~2025). 같은 종류면 예전 자료 대신 최근 것 사용.
- **한국** 데이터 우선, 부족분만 해외 보완.
- **배터리** 관련 자료 우선, 없으면 배터리 공정에 가까운 자료 → 일반 제조는 보조만.

|------|-----------|------------------|
| **설비별 전력 시계열** | 공장 단위 공개 데이터 없음 | SPARK(Karlsruhe), HIPE — 설비별·고해상도 학습·이상치 참고 |
| **공정별 단위 생산당 전력(kWh/kWh)** | 에너지공단·KESIS에 세부 없음 | MDPI 2025(헝가리 배터리 공장) — 이미 README_ESG_Rule_및_설비기준.md §2에 반영 |
| **설비 정격(kW)** | 업종 공통 표 없음 | MTI·켐시스템(한국어 페이지) 카탈로그 — 이미 사용 중 |

→ **기준은 한국(요금·수요·KESIS)** 로 두고, **설비/공정 세부 수치**만 해외 논문·카탈로그로 보완하는 구조.

### 4.4 생산·손실·폐기물

| 구분 | 한국 | 비고 |
|------|------|------|
| **산출물(양품)** | 자사 measurements·MES | 한국 공개 “공정별 산출물 시계열” 없음 |
| **손실량·산출 폐기물** | 자사 MES·생산실적 | 한국 공개 시계열 데이터셋 없음. 실무는 자사 데이터 사용 |

→ **한국**에는 손실량·산출 폐기물 참고용 공개 데이터 없음.

#### 4.4.1 손실·폐기물 — 참고는 **배터리 관련**만

- **원칙**: 손실량·산출 폐기물 참고는 **배터리(자동차 배터리) 관련** 자료만 쓴다. 일반 제조(기어모터, 금속 채굴 등)는 참고하지 않음.
- **현황**: 배터리 공정의 손실량·산출 폐기물 **공개 시계열·벤치마크**는 국내·해외 모두 거의 없음. **MDPI 2025**(헝가리 배터리 공장)는 에너지·물·NMP·GHG만 있고, scrap/waste 수치는 없음.
- **임의 생성할 때 쓸 통상 참고치**: 공개 표는 없어도, **배터리 제조 논문·LCA에 자주 나오는 수율·손실률**을 모아 둔 **통상 참고치**가 있으면 그걸로 더미/학습 데이터를 만들 수 있음.  
  → **`README_배터리_손실량_폐기물_통상참고치.md`** 에 공정별 scrap/waste 비율·범위를 정리해 두었으니, **취업 준비·포트폴리오용 임의 생성** 시 그걸 가져다 쓰면 됨.
- **실무**: 자사 MES·생산실적이 쌓이면 그 데이터로 위 통상치를 갱신하면 됨.
