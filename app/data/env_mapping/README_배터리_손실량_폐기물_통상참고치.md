# 배터리 물질 손실량·산출 폐기물 — 통상 참고치 (임의 생성용)

**문서 갱신(구현 동기화)**: 2025-03 — §4에 `run_generate_measurements`가 본 문서 §3.2를 파싱해 `profile.json`의 scrap/waste를 자동 산출하는 내용 반영.  
**env_mapping 문서 3종**: 본 파일(손실·폐기) + `README_ESG_맥락_및_현황.md` + `README_ESG_Rule_및_설비기준.md`.

**관점**: **배터리 물질** 기준 — 원자재·전극·셀 **물질의 손실**과 공정에서 나오는 **물질로서의 산출 폐기물**만 다룸.  
**목적**: 공개된 배터리 전용 표는 없어도, **임의로 더미/학습 데이터를 만들 때** 쓸 수 있는 **통상적인 범위**를 한곳에 모아 둠.  
**취업 준비·포트폴리오**용으로 “아무 숫자”가 아니라 “배터리 물질 관점에서 통상 쓰는 구간”으로 생성하려면 아래를 쓰면 됨.

---

## 1. 정의 (물질 관점)

| 구분 | 의미 (배터리 물질 관점) |
|------|-------------------------|
| **손실량 (물질 손실)** | 공정에서 **원자재·전극재·셀 소재**가 양품으로 나가지 않고 **유실·불량·트리밍** 등으로 빠지는 **물질량**. (슬러리 손실, 코팅 트리밍, 건조 손실, 불량 전극·불량 셀 등.) |
| **산출 폐기물** | 공정 **산출물 중 폐기·처리 대상이 되는 물질** — 불량품(물질), 오프스펙 전극/셀, 공정 부산물(슬러지, 사용 후 용매 등) 중 최종 폐기되는 부분. |

→ 단위는 **물질량**(kg, ton) 또는 **생산량(EA) 대비 비율**로 둘 수 있음. 더미에서는 production(EA)과 맞추려면 “production 대비 물질 손실·폐기 비율”로 환산해 쓰면 됨.

---

## 2. 출처 (최근 자료 기준)

- **공개된 “배터리 물질 손실률·산출 폐기물률” 단일 표** 는 없음.
- **참고한 쪽**: 아래 **최근(2023~2025)** 배터리 문헌 + 2020년대 LCA·메타분석에 산재된 수치를 종합해 통상 범위로 정리함.

| 출처 | 연도 | 내용 | 손실량·폐기물 |
|------|------|------|----------------|
| **Kuki et al., MDPI Environments** | **2025** | 헝가리 배터리 공장 3곳(CATL, Samsung SDI, SK) 에너지·물·NMP·GHG. 공개 데이터 기반. | NMP 0.51~0.56 kg/kWh 셀 — 용매 소비·회수. **물질 손실률·폐기물률은 미제시.** |
| **Kallitsis (메타분석)** | 2020년대 인용 | LIB 제조 에너지 30~50 kWh/kWhcell. MDPI 2025에서 인용. | 손실률 직접 제시 없음. |
| **GREET Battery Module** | 2023 | Argonne, 배터리 LCA·물질흐름. 오픈 액세스. | 물질 수요·공정별 입력 가능. 손실률/폐기물률은 모델·문서 확인 필요. |

- **MDPI 2025** 논문·보조자료: https://www.mdpi.com/2076-3298/12/1/24 ; Supplementary(엑셀): https://www.mdpi.com/article/10.3390/environments12010024/s1 → `app/data/env_mapping` 에 넣어 쓸 수 있음(§6 참고).

- **물질 손실률·산출 폐기물률**을 **직접 제시한 2023~2025 단일 논문**은 없음. 위 통상 범위(90~97% 수율, 3~10% 손실, 1~4% 폐기물)는 **2020년대 배터리 LCA·제조 문헌에 산재된 수치**를 종합한 것이며, “공식 기준”이 아니라 **임의 생성 시 참고치**로만 씀.

## 3. 통상 참고치 요약 (배터리 물질 관점)

### 3.1 물질 수율·물질 손실률 (전체)

| 구분 | 통상 범위 | 비고 |
|------|-----------|------|
| **전극/셀 물질 수율** | **약 90~97%** | 활물질·전극·셀 단계에서 “투입 물질 대비 양품으로 나가는 물질” 비율. |
| **물질 손실률** | **약 3~10%** | 투입 원자재 중 유실·트리밍·불량으로 손실되는 비율. 코팅·건조·셀 조립 구간에서 인용됨. |
| **산출 폐기물(물질)** | **양품 대비 약 1~4%** | 공정에서 나오는 폐기 물질(불량 전극·불량 셀·공정 부산물 등)을 양품 물질량 대비로 본 비율. |

→ **임의 생성** 시: `production`(양품)을 먼저 정한 뒤, **손실량(scrap) ≈ production 대비 3~8%**, **산출 폐기물(waste) ≈ production 대비 1~3%** 같은 **물질 비율**로 두고, 공정별로 아래처럼 조정하면 됨.

### 3.2 공정별 — 물질 손실량·산출 폐기물 (임의 생성용)

| 공정(process) | 물질 손실량 — production 대비 | 산출 폐기물 — production 대비 | 참고 (물질 관점) |
|----------------|------------------------------|--------------------------------|-------------------|
| **mixing** | 2~5% | 0.5~1.5% | 슬러리 유실, 배치 불량, 용매(NMP) 손실·회수 미달. |
| **plate** (코팅·성형 등) | 2~6% | 1~2% | 전극 트리밍, 코팅 불량, 건조 손실. |
| **cell** | 3~8% | 1~3% | 전극·분리막·전해질·케이스 등 셀 소재 불량·스크랩, 검사 불량. |
| **module** | 1~4% | 0.5~1.5% | 모듈 조립 단계 물질 손실·불량 셀·연결재 등. |
| **pack** | 0.5~3% | 0~1% | 팩 단계 물질 손실·폐기. |

- **단위**: production과 맞추려면 EA 동일 단위로 두거나, **물질량(kg)** 이면 “production 1EA당 kg” 비율로 환산.
- **계산 예**: production=100(EA) 이고, cell 공정이면 물질 손실량 3~8 → scrap 3~8, 산출 폐기물 1~3 → waste 1~3 (EA 또는 물질량 비율).

### 3.3 “기준치”로 쓸 때 (물질 관점)

- **정상 상한**: 위 **물질 손실률·산출 폐기물 비율**의 위쪽(예: 8%, 3%)을 넘으면 “이상”으로 보면 됨.  
  예) `scrap / production ≤ 0.08`, `waste / production ≤ 0.03` 같은 **기준치(임계치)**.
- **정상 범위**: 더미 생성 시에는 위 **통상 범위** 안에서만 샘플링하면 “배터리 물질 관점에서 통상적인” 수준이 됨.

## 4. 더미 데이터 생성 시 적용

### 4.1 수동·전략 문서로 맞출 때

- **docs/esg-dummy-data-strategy.md** 프로파일 표에서 **정상 scrap(물질 손실량)**, **정상 waste(산출 폐기물)** 범위를 정할 때:
  - **production 대비 비율**로 위 3.1·3.2를 쓰고,
  - 공정별로 `scrap = production × (해당 공정 물질 손실 비율)`, `waste = production × (해당 공정 산출 폐기물 비율)` 로 **통상 범위**를 계산해 넣으면 됨.
- 예: cell L2, production 60~100 → 물질 손실 3~8%면 1.8~8, 산출 폐기물 1~3%면 0.6~3 → **정상 scrap 2~8, 정상 waste 1~3** 처럼 표에 넣으면 됨.

### 4.2 현재 파이프라인(자동 반영)

- **스크립트**: `app/training/pipelines/esg_dummy/run_generate_measurements.py` — `build_profile()` → `_load_scrap_waste_reference_from_readme()`.
- **입력**: 본 문서 **§3.2 표** (`| **mixing** | …% | …% |` 형식, 공정 `mixing`~`pack`)를 정규식으로 읽어 공정별 손실·폐기 **비율 구간**을 추출.
- **출력(`profile.json`)**: 각 라인의 **`production` 밴드** `[p_lo, p_hi]`에 곱해  
  `scrap = [round(p_lo×s_lo, 1), round(p_hi×s_hi, 1)]`, `waste = [round(p_lo×w_lo, 1), round(p_hi×w_hi, 1)]` 로 **절대 구간**을 덮어씀.
- **실패 시**: 이 README가 없거나 표가 안 맞으면 해당 단계를 건너뛰고 코드 내 **기본 `DEFAULT_PROFILE`**의 scrap/waste를 사용.
- **측정 행 샘플링**: 정상 등에서는 위 구간에서 균등 샘플. 다변량 `MULTIVARIATE_SCRAP_WASTE_DEVIATION`만 상한 대비 scrap **약 1.12~1.38배**, waste **약 1.10~1.32배**(라벨·검증용). 상세는 `app/training/pipelines/esg_dummy/README.md`.

## 5. 정리

- **배터리 물질 손실량**·**산출 폐기물**은 공개된 전용 표가 없어도, 위 **통상 참고치(물질 관점)** 를 가져와서 **임의 생성**에 쓸 수 있음.
- **취업 준비** 시: “배터리 제조·물질흐름 논문에서 통상 인용되는 **물질 수율·물질 손실·산출 폐기물** 수준을 참고해 더미 데이터를 생성했다”고 설명할 수 있음.
- 실무에서 실제 물질 단위 데이터가 쌓이면, 그때 **자사 데이터**로 위 비율·기준치를 갱신하면 됨.

## 6. `app/data/env_mapping` 에 넣을 수 있는 데이터

- **MDPI 2025 (Kuki et al.)** 논문 **Supplementary Materials** 에 **엑셀 파일**이 있음.  
  - **Battery factories impact.xlsx**, **Energy_water_gas_emissions.xlsx**  
  - 다운로드: https://www.mdpi.com/article/10.3390/environments12010024/s1  
  - 위 링크에서 받아서 **`app/data/env_mapping`** 폴더에 저장해 두면, 배터리 공장별 에너지·물·가스·배출 등 **수치 참고**로 쓸 수 있음. (손실량·산출 폐기물 컬럼은 없을 수 있음.)
- **GREET Battery Module** 은 Argonne 사이트에서 모델·데이터를 받을 수 있음. 물질흐름 데이터를 내려받을 수 있으면 같은 폴더에 두고 참고 가능.
- 그 밖에 **배터리 물질 손실·산출 폐기물** 시계열/표를 제공하는 **공개 데이터셋**(Zenodo, Figshare 등)을 찾으면, 동일하게 `app/data/env_mapping` 에 넣어서 사용하면 됨.
