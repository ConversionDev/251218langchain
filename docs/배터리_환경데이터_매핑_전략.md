# 배터리 환경데이터 매핑 전략 (EC 번호 조회·포맷)

**목표**: `환경 데이터 매핑 테이블.xlsx`와 **동일한 포맷**만 사용해, 배터리 관련 물질만 선별하고 EC 번호를 ECHA 등 참고 소스로 조회·매핑한다.

---

## 1. 사용할 Excel 포맷 (원본 + 4출처 첨부 열)

기본 열은 **환경 데이터 매핑 테이블.xlsx**와 동일하고, **ECHA·GESTIS·PubChem·NCIS 네 출처를 모두 첨부(기입)**할 수 있도록 아래 열을 둔다.

### 1.1 공통 열 (원본과 동일)

| 열 이름 | 설명 |
|--------|------|
| 내부 표기명 | 물질 표준명 또는 별칭 (1행 = 1별칭) |
| 표준그룹 | 예: BAT(배터리) |
| CAS 번호 | 먼저 확보 (물질의 고유 식별자) |
| EC 번호 | **ECHA 1차 확보** 값 (형식: XXX-XXX-X 7자리) |
| 영문명 | 영문 표준명 |
| MSDS 기준명 | 국문 MSDS/안전정보 기준명 |
| 관련 ESG 지표 | 예: 배터리 원자재 |
| 산업 분류 | 예: 배터리 제조 |
| 필수/선택 | 필수 또는 선택 |
| 표준 단위 | 해당 시 단위 |
| 비고 | 언어 라벨(영문/국문 등) 또는 메모 |

### 1.2 4출처 첨부 열 (반드시 채울 것)

| 열 이름 | 출처 | 용도 |
|--------|------|------|
| EC 번호 | **ECHA** | EC 번호 1차 확보 (가장 정확·공식) |
| GESTIS 검증 | **GESTIS** | MSDS·EC/CAS 병기 검증 (Y·URL·메모) |
| PubChem 검증 | **PubChem** | CAS/EC 교차 검증·배터리 첨가제 (CID·Y·메모) |
| NCIS 참조 | **NCIS** | 국문 MSDS·국내 규제 (물질번호·URL·메모) |

- **행 규칙**: 1행 = 1별칭(내부 표기명). 완전 동의어만 별도 행으로 추가.
- **4출처**: ECHA → GESTIS → PubChem → NCIS 순으로 모두 확인·기입 후, 제조사 MSDS와 최종 대조.

## 2. EC 번호 조회 전략 (우선순위)

데이터 시트 작성 시 **아래 순서**로 진행하면 오류를 줄일 수 있다.

### 2.1 1단계: CAS 번호 확보

- 배터리 물질 목록: `app/data/env_mapping/battery_substances.csv` (cas, name_en, name_ko, battery_related=1).
- 이름은 유사 명칭이 많으므로 **CAS를 기준**으로 매핑한다.
- 통칭(예: NMC 811, Lithium salt)은 가능하면 표준 명칭으로 치환 후 매핑하면 인식률이 높다.

### 2.2 2단계: EC 번호 조회 (우선 ECHA)

| 순위 | 소스 | 용도 | 비고 |
|------|------|------|------|
| **1** | **ECHA (유럽 화학물질청)** | EC 번호 **공식 확인**, REACH 등록·유해성 분류 | EC 번호의 기원, 신뢰도 최고. CAS 또는 물질명으로 검색. |
| 2 | GESTIS (독일 IFA) | MSDS 상세·EC/CAS 병기 검증 | 글로벌 MSDS 표준 참고. |
| 3 | PubChem (미국 NLM) | CAS/EC 교차 검증, 신규/첨가제 확인 | Safety Summary에서 MSDS 요약 참고. 현재 파이프라인에서 EC API 사용 중. |
| 4 | NCIS (국내) | 국문 MSDS·국내 규제 | 국문 명칭·CAS로 검색. |

- **실무 순서**: CAS 확보 → **ECHA에서 EC 번호 추출** → **GESTIS·PubChem·NCIS 각각 검증·참조 기입** (네 출처 모두 첨부).
- **EC 형식**: XXX-XXX-X (7자리 숫자).
- **사이트**: [ECHA Substance Information](https://echa.europa.eu/substance-information/-/substanceinfo/100.000.000) (물질명 또는 CAS로 검색).

### 2.3 3단계: 공급사(Vendor) MSDS와 최종 대조

- 가장 정확한 MSDS는 해당 원재료를 납품하는 제조사(BASF, 솔베이, 엔켐 등) 문서.
- ECHA/공식 DB 값과 제조사 MSDS를 대조한 뒤 최종 값을 시트에 반영.

## 3. 배터리만 뽑아오는 작업 흐름

1. **입력**
   - `battery_substances.csv`에서 `battery_related == 1`인 CAS·name_en·name_ko 목록.
   - (선택) 기존 `환경데이터_매핑_보강.xlsx` 또는 `환경 데이터 매핑 테이블.xlsx`.

2. **포맷**
   - 출력은 **§1 공통 열 + 4출처 첨부 열**(EC 번호, GESTIS 검증, PubChem 검증, NCIS 참조) 사용.

3. **EC 번호 채우기**
   - CAS별로 ECHA에서 EC 번호 조회 (1차).
   - 없거나 불확실하면 PubChem → GESTIS/NCIS 순으로 보조 조회.

4. **산출물**
   - **배터리 전용 시트** 1개: 동일 포맷으로 배터리 물질만 행 구성.
   - 파일명 예: `환경데이터_매핑_보강_배터리.xlsx` (또는 팀 규칙에 맞게).

## 4. 현재 코드베이스와의 연동

- **배터리 전용 Excel 생성**: `python -m app.data.env_mapping.export_battery_only` 실행 시 **4출처를 자동으로 조회해 시트에 채움**.
  - **EC 번호**: 1차 GESTIS(CAS/EC 테이블), 없으면 PubChem. (ECHA는 공개 API 없어 자동화 시 GESTIS로 대체.)
  - **GESTIS 검증**: GESTIS 테이블에서 해당 CAS 있으면 링크 또는 Y. 테이블은 `gestis_zvg_cas_list.xlsx`(자동 다운로드 시도, 실패 시 수동 배치).
  - **PubChem 검증**: PubChem CID.
  - **NCIS 참조**: 환경변수 `NCIS_API_KEY` 또는 `DATA_GO_KR_API_KEY` 설정 시 공공데이터 API 조회 후 Y 등 기입.
- **원본 포맷 정의**: `vocabulary_builder.ORIGINAL_COLUMNS` + GESTIS 검증 / PubChem 검증 / NCIS 참조 열.
- **배터리 CAS 집합**: `battery_substances.csv`에서 `battery_related=1`인 CAS 사용.
