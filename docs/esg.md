# ESG · 공정 전력 시계열 이상치 탐지 방향성

> 원청 ESG 시스템에서 **공정(PCF) 전력** 데이터에 대한 시계열 분석·이상치 탐지 담당 파트의 목적, 플로우, 설계를 정리한 문서.

---

## 1. 전체 플로우에서의 위치

```
원청 데이터 입력 (구매팀 + PCF(공정) 데이터)
        ↓
    데이터 저장
        ↓
  Validation (데이터 유효성 검사)
        ↓
  시계열 이상치 탐지  ← **본인 담당 (공정 쪽 전력)**
        ↓
  원청 대시보드 표시
```

- **담당 범위:** PCF(공정) 데이터 중 **전력만** 시계열·이상치로 다룸.
- **타이밍:** Validation 통과 후, 유효성은 통과했지만 이상할 수 있는 값에 대해 시계열 분석으로 이상치 검증.
- **확장:** 용수·LNG는 동일 포맷으로 나중에 확장 가능하나, 당분간은 **전력 중심 시계열만** 대상.

---

## 2. 원청이 보는 관점 (이상 유형)

| 유형 | 의미 | 예시 | 원청 대응 |
|-----|------|------|-----------|
| **Drift (지속 상승/하락)** | 설비 효율 저하, 노후화, 공정 비효율 | 단위 생산 전력 1월 3.1 → 2월 3.3 → 3월 3.6 kWh | **에너지 효율 문제** → 개선 요청 |
| **기저전력 증가** | 설비 미정지, 공조 지속, 누설, 압축기 대기전력 | 야간 전력 80kW → 130kW | **에너지 낭비** → ESG KPI 직결 |
| **구조적 변화** | 설비 증설, 공정 추가, 생산 증가, 데이터 오류 | 평균 전력 1~6월 1000 MWh, 7월~ 1600 MWh | **Change Point Detection**으로 확인 |
| **데이터 품질 이상** | 계측기/인터페이스/단위 오류, 누락 | 전력 -120 kWh, 갑자기 0 | 데이터 품질 이슈로 처리 |

---

## 3. 원청 지표 TOP3

1. **단위 생산 전력** (kWh/unit)
2. **기저전력 비율** (%)
3. **전력 사용량 Drift**

---

## 4. 테이블 설계 (3단계)

### 4.1 운영 DB (Raw) – 수집용

- **목적:** 원청에서 들어오는 전력 데이터를 **가공 없이** 저장.
- **테이블:** `energy_usage_raw`

| 컬럼 예시 | 설명 |
|-----------|------|
| process | 공정 |
| energy_type | electricity 등 |
| usage_amount | 사용량 |
| unit | kWh 등 |
| measured_at | 측정 시각 |

- **역할:** 기록 보존, 재처리 가능. 이상치 포함 가능.

---

### 4.2 데이터 마트 – 분석용 통합

- **목적:** 생산량·공정별 전력 등 **분석용 정리/집계**.
- **테이블:** `energy_usage_mart`

| 컬럼 예시 | 설명 |
|-----------|------|
| month | 연월 |
| process | 공정 |
| electricity_kwh | 전력 사용량 |
| production_qty | 생산량 |
| energy_intensity | 단위 생산 전력 등 |

- **역할:** 생산량과 통합, 분석 용도 최적화. **AI 이상치 탐지·시계열 분석은 이 레이어에서 수행.**

---

### 4.3 KPI/분석 레이어 – 계산 지표·AI용

- **목적:** Drift, baseline, 이상치, 단위 생산 전력 등 **AI/대시보드용 지표 계산**.
- **테이블:** `energy_usage_analysis`

| 컬럼 예시 | 설명 |
|-----------|------|
| month, process | 연월, 공정 |
| electricity_kwh, production_qty, energy_intensity | 마트와 동일 |
| baseline | 기저/기준선 |
| z_score | 이상치 점수 |
| drift | Drift 지표 |

- **필요 정보:** 전년 대비 변화율, 전월 대비 변화율, 이동 평균, 이상치 판단, 이상 여부.
- **역할:** **공정별 전력 사용량 시계열 이상치 분석** 결과 저장. 대시보드·원청 지표 연동.

---

## 5. 데이터 소스 및 전처리

- **원천:** UCI Electricity Load Diagrams 2011–2014 / Zenodo – Residential Power & Battery Data.
- **프로젝트 내 파일:** `app/data/env_mapping/electricity_hourly_dataset.tsf`
  - 321개 시리즈, 2012–2014, **시간 단위(kW)**.
  - TSF 표준 포맷, 시리즈당 한 row (긴 시계열).
- **변환 방향:**
  - 시간별 → **월별 시계열** 집계.
  - **전년 대비** 비교용 파생 컬럼 생성.
  - 시리즈 ID → **공정(process)** 매핑 테이블로 공정별 분석 가능하게 구성.
- **단위:** 원본 kW → 에너지 지표는 kWh 환산 규칙 명시 (예: 1시간 평균 kW → kWh).

---

## 6. AI·다변량 고려

- **다변량 패턴:** 전력·생산량·공정이 동시에 영향을 주는 경우, 단순 상관이 아닌 **다변량 패턴**으로 인지할 수 있도록 학습/분석 설계 필요.
